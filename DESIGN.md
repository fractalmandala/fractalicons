# DESIGN

Design principles and visual rules for this project.

## Principles
- Clarity before decoration.
- Consistency over one-off styling.
- Accessible, keyboard-friendly interactions.
- Use existing components and patterns before creating new ones.

## Tokens
- Prefer design tokens and theme variables over hard-coded values.
- Keep spacing, typography, radius, and color scales consistent.

## Layout
- Use established layout primitives and containers.
- Maintain responsive behavior and readable density.

## States
- Define clear hover, focus, active, disabled, loading, and error states.
- Preserve contrast and motion preferences.

## Notes
- Project-specific visual decisions belong in this file as the project evolves.
